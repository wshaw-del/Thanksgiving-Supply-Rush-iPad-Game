THANKSGIVING SUPPLY RUSH - THREE APPROVED ARTWORK SAMPLES

Contents: index.html and six JPG image files p0a.jpg through p2b.jpg.

HOW TO INSTALL TO YOUR EXISTING GITHUB PAGES SITE
1. Unzip this package on your Windows computer.
2. Open https://github.com/wshaw-del/Thanksgiving-Supply-Rush-iPad-Game
3. Click the samples folder. (Do not edit the root-level index.html.)
4. GitHub does not always allow replacing a same-named file through the Upload Files page.
   If GitHub gives a same-name conflict, delete the seven old files inside samples and commit,
   THEN upload the seven new files into samples and commit. This is safe only inside samples.
5. Use Add file > Upload files inside samples; select index.html and six .jpg images.
6. Open https://wshaw-del.github.io/Thanksgiving-Supply-Rush-iPad-Game/samples/?v=9
   in Safari on iPad. GitHub Pages may take a few minutes to refresh.

IMPORTANT
* This is a THREE-PUZZLE single-device visual/gameplay sample. It is NOT your connected
  two-iPad multiplayer game, which remains in root-level index.html.
* Both images appear side-by-side on landscape iPad. The art is cropped from the
  three pairs you approved. The Thanksgiving scene is squarer, while the other
  two are naturally panoramic, so their on-screen heights differ.
* The samples were checked for file completeness and all 3 tap regions per puzzle;
  final difficulty and any incidental visual differences should still be
  checked on your actual iPad before creating the entire 75-puzzle library.
